# План разработки: «Хранители Долины» (рабочее название)

3D tower defense для браузера (ПК + мобильные), в стилистике референсов: изометрическая «миниатюрная» камера сверху, сочная трава, скалы-хребты, тропы, башни-баллисты, армии в красном, слоны, щитовые построения, россыпи монет.

**Статус:** черновик на согласование.

---

## 1. Технологии

| Слой | Выбор | Почему |
|---|---|---|
| Язык / сборка | **TypeScript + Vite** | Быстрая сборка, hot reload, маленький бандл, типы ловят ошибки |
| 3D-движок | **Three.js** (+ `postprocessing`, `n8ao`) | Лёгкий (~150 КБ gz), лучший баланс «просто кодить» / «хорошая картинка», огромная экосистема. Babylon.js мощнее «из коробки», но в 5–8 раз тяжелее — плохо для веб-порталов и мобилок |
| UI / экраны | **HTML/CSS-оверлей + Preact** | Меню, магазин, карта, настройки — проще и красивее в DOM, чем в WebGL; Preact весит ~4 КБ |
| Аудио | **Web Audio API** (своя обёртка, шины music/sfx) | Полный контроль паузы/громкости/дакинга, без лишних зависимостей |
| Сохранения | localStorage + адаптер облачного сохранения платформы | Работает сразу, облако подключится вместе с SDK |
| Деплой для тестов | GitHub Pages / любой статический хостинг | Сразу проверять на телефоне |

**Честно про графику.** Референсы — это пре-рендеренный маркетинговый арт уровня AAA, в реальном времени на мобильном браузере 1:1 его не повторить. Цель — максимально близкий стилизованный вид за счёт:
- PBR-освещения, мягких теней от «солнца», ACES-тонмаппинга, HDR-окружения;
- пост-обработки: **tilt-shift** (даёт тот самый «игрушечный» вид референсов), SSAO, bloom, цветокоррекция (LUT), виньетка;
- шейдерного террейна (трава/тропа/камень со смешиванием по маске), инстанс-травы с ветром, инстанс-деревьев, скальных хребтов;
- частиц: пыль, искры попаданий, огонь, дым, взрывы, следы стрел, фонтаны монет, всплывающий урон, тряска камеры, хит-флеш.

Пресеты качества **Low / Medium / High / Auto** (автоопределение по FPS) — чтобы слабые телефоны держали 30–60 FPS.

## 2. Ассеты (генерирую сам)

- **3D-модели:** базово — CC0-паки стилизованной low-poly графики (Quaternius, KayKit, Kenney — свободная лицензия, коммерция разрешена) + процедурные модели, которые я пишу кодом (башни, хребты, частоколы, мосты, деревья). Все модели подключаются через манифест ассетов, поэтому позже любую можно заменить на более качественную без переписывания кода.
- **Текстуры:** процедурная генерация (шум, тайлы травы/земли/камня), запекаю в файлы.
- **Иконки UI:** SVG, рисую сам (башни, монеты, бустеры, кнопки).
- **Звуки (SFX):** синтез (sfxr-подход + слои + обработка) + CC0-библиотеки: выстрел баллисты, свист стрелы, удар по щиту, взрыв, топот слона, боевой рог, монеты, клики UI, апгрейд, победа/поражение.
- **Музыка:** генерируется процедурно (композиция → рендер в OGG/MP3): тема меню, 5 боевых тем по биомам, тема босса, джинглы победы/поражения. Синтезированная музыка будет приличной, но проще студийной — архитектура позволяет потом подменить файлы на лицензионные треки.

## 3. Геймдизайн (своя игра, не копия)

### 3.1 Ядро
- Враги идут по тропе к воротам деревни; у игрока **жизни** (ворота) и **золото уровня**.
- Башни строятся только на **участках-слотах** с ценой (как «5» и «25» на референсах). Слоты можно покупать по ходу — открывают новые позиции.
- **Герой-командир** (конный лучник) — управляется игроком: клик/тап по земле или WASD. Стреляет сам, имеет 2 активных умения, прокачивается.

### 3.2 Уникальные механики (отличие от клонов)
1. **Монеты падают на поле** — враги роняют золото (как на референсе 2). Герой собирает его магнитом в радиусе; несобранное само собирается через N секунд с потерей части. Даёт смысл двигать героя, а не только строить.
2. **Строевые формации врагов** — «черепаха» из щитов блокирует фронтальные снаряды (лучники/баллисты отскакивают), её ломают катапульты/магия/огонь или удар во фланг. Колонны идеально пробиваются баллистой насквозь.
3. **Синергия соседних башен** — пары рядом стоящих башен дают бонусы (напр. Огонь + Баллиста = горящие болты). Мотивирует продумывать застройку.
4. **Рельеф** — скальные хребты блокируют линию огня низких башен; высокие башни/катапульты стреляют поверх.

### 3.3 Башни (за монеты, 3 уровня + выбор из 2 специализаций на 4-м)
| Башня | Роль | Специализации |
|---|---|---|
| Лучники | Быстрый одиночный урон | Снайперы / Залповые |
| Баллиста | Пробивает насквозь линию врагов | Тяжёлая (стан) / Скорострельная |
| Катапульта | Урон по площади, ломает щиты | Огненные горшки / Валуны (оглушение) |
| Башня мага | Игнорирует броню, замедляет | Молнии (цепь) / Лёд |
| Казармы | Солдаты блокируют дорогу | Рыцари / Копейщики (против кавалерии/слонов) |
| Жаровня | Огонь по площади, DoT | Масляный ров / Огненный столп |
| Колокольня | Поддержка: бафф скорости соседей, +золото | — |

Башни открываются по мере прохождения + часть покупается в магазине.

### 3.4 Враги (5 биомов добавляют новых)
Пехотинец · Бегун · Лучник (стреляет по герою/солдатам) · **Щитовая черепаха** (формация) · Знаменосец (бафф) · Лекарь · **Бронированный великан** · Всадник · **Боевой слон** (огромный HP, топчет солдат, несёт стрелков) · **Носорог-таран** (рывок) · Таран/осадная башня · Летучие (на поздних биомах).
**Боссы** каждые 10 уровней: Вождь на мамонте, Осадная башня, Огр-кузнец, Колдун и т.д. — с фазами и спецатаками.

### 3.5 Герои
- Рыцарь-лучник (стартовый), Паладин (ближний бой, щит), Чародейка (AoE) — за монеты/звёзды.
- 1 уникальный герой — только за рекламу 3/3 (см. 5.3).
- Умения: «Залп стрел», «Боевой клич», «Рывок» и т.п.; прокачка героя за опыт + монеты.

### 3.6 Заклинания и бустеры
- **В бою (кнопки с перезарядкой, расходники за монеты):** Метеор, Ледяная волна, Подкрепление, Золотая лихорадка (×2 золото 30 с), Починка ворот (+жизни), Замедление времени.
- **Перед уровнем:** +стартовое золото, +жизни, первая башня сразу 2-го уровня, ×2 опыт героя.

### 3.7 Мета-прогрессия
- **Монеты** (общая валюта) — награда за уровни, тратятся в магазине и кузнице.
- **Звёзды** (1–3 за уровень, по оставшимся жизням) — открывают новые биомы и дерево улучшений.
- **Кузница / дерево улучшений** — постоянные бонусы к башням, герою, заклинаниям.
- Ежедневная награда, ежедневное колесо фортуны (через ревардед).

## 4. Уровни: 100 штук — гибридный подход (рекомендую)

- **5 биомов × 20 уровней:** Луга → Каньоны → Побережье → Снежные перевалы → Выжженные руины. Босс на каждом 10-м уровне.
- **Уровни 1–20 — ручные**: обучение, ввод механик по одной, отточенный баланс (это решает удержание игроков).
- **Боссовые уровни (30, 40 … 100) — ручные.**
- **Остальные 21–99 — процедурная генерация по сиду**: уровень N всегда одинаковый у всех игроков. Генератор:
  1. строит тропу (случайное блуждание по сетке с ограничениями на длину/повороты; с 30-го уровня — развилки и 2 входа);
  2. ставит слоты башен в точках с лучшим покрытием тропы;
  3. обрамляет тропу скальными хребтами/частоколом/деревьями по шаблонам биома;
  4. собирает волны из «бюджета сложности» по формуле от номера уровня из пула открытых врагов;
  5. валидирует уровень **авто-симуляцией** (бот-игрок в headless-режиме) — слишком лёгкие/невозможные отбраковываются.
- **После 100 — бесконечный режим** (рекорд волн) — дополнительные показы рекламы без новой разработки.
- Для ручных уровней — встроенный **dev-редактор уровней** (рисую тропу и слоты прямо в игре → JSON).

## 5. Реклама (агрессивность выше среднего)

### 5.1 Архитектура
- `AdService` с единым интерфейсом `showInterstitial()` / `showRewarded(placement)` и провайдерами: **StubProvider** (сейчас) → позже Yandex Games / CrazyGames / Poki / GameDistribution / VK Play — подключаются одним файлом-адаптером.
- **Заглушка:** полноэкранный оверлей «Реклама (заглушка)» с таймером 3–5 с; для ревардед — кнопка «закрыть досрочно» (без награды), dev-переключатели «нет рекламы / ошибка» для проверки всех веток.
- Все частоты и места показов — в одном конфиге (позже можно грузить удалённо и крутить без релиза).

### 5.2 Общие принципы (реализуются сразу)
- На время рекламы: **пауза игрового цикла, пауза/mute всей музыки и звуков** (suspend AudioContext), блок ввода; после — корректное возобновление.
- Пауза + mute при сворачивании вкладки/потере фокуса (`visibilitychange`, `blur`).
- **Отключены:** контекстное меню и ПКМ, выделение текста, drag картинок, long-press-меню на iOS/Android, pinch-zoom и double-tap-zoom браузера, Ctrl+колесо, «оттягивание» страницы (overscroll).
- Звук разблокируется по первому жесту пользователя (требование браузеров).

### 5.3 Места показов
**Interstitial (полноэкранная):**
- после каждого завершённого уровня (победа/поражение), начиная с 3-го;
- при рестарте уровня;
- при выходе из уровня на карту;
- по возвращении в игру после долгого простоя в меню;
- в бесконечном режиме — каждые N волн в перерыве;
- ограничитель: минимум 60 с между показами (настраивается; у большинства платформ это требование), первый показ не раньше ~2 мин сессии.

**Rewarded (по желанию игрока):**
- ×2 / ×3 награда после победы;
- **«Второй шанс»** при поражении (+жизни, продолжить волну) — 1 раз за уровень;
- бесплатные монеты в магазине (лимит в день);
- бесплатный бустер перед уровнем;
- **«Королевский обоз»** — во время боя по полю иногда едет золотая повозка: тап → реклама → много золота;
- ежедневный сундук и колесо фортуны;
- мгновенная перезарядка заклинания.

**Уникальные предметы только за рекламу — прогресс 0/3 → 3/3 (сохраняется между сессиями):**
- 🐉 Башня «Логово дракона» — огненное дыхание по конусу;
- 🦅 Герой «Валькирия на грифоне» — летает над рельефом;
- ☄️ Заклинание «Звездопад»;
- 🔥 «Знамя феникса» — авто-воскрешение ворот 1 раз за уровень;
- 🐕 Питомец «Золотой пёс» — сам собирает монеты;
- 👑 Скин «Золотое королевство» для всех башен.

## 6. Экраны

1. **Загрузка** — прогресс-бар, подсказки.
2. **Главное меню** — фоном живая 3D-деревня (как референс 1), кнопки: Играть, Карта, Магазин, Кузница, Настройки, ежедневная награда.
3. **Карта уровней** — прокручиваемая карта 5 биомов, 100 узлов на тропе, звёзды, замки боссов, замочки на закрытых биомах.
4. **Магазин** — вкладки: Башни, Герои, Бустеры, Заклинания, **Уникальное (3/3)**, Монеты (за рекламу).
5. **Кузница** — дерево постоянных улучшений.
6. **Настройки** — громкость музыки/звуков, качество графики, язык (RU/EN), вибрация, подсказки управления, сброс прогресса.
7. **Бой (HUD)** — жизни, золото, волна N/M, кнопка «следующая волна раньше» (+бонус), скорость ×1/×2, пауза, панель заклинаний, портрет героя.
8. **Окна:** пауза, победа (звёзды, награда, ×2 за рекламу), поражение (второй шанс), выбор бустеров перед уровнем, туториал.

Интерфейс адаптивный: **портрет на мобилках (как референсы) и ландшафт на ПК** — камера автоматически подгоняет поле под экран.

## 7. Управление

| Действие | ПК | Мобильные |
|---|---|---|
| Строить/улучшить | ЛКМ по слоту → радиальное меню | Тап по слоту → радиальное меню |
| Двигать героя | ЛКМ по земле или WASD/стрелки | Тап по земле |
| Камера | Перетаскивание, колесо — зум | Свайп, щипок — зум |
| Заклинания | Q / W / E (+ клик по цели) | Кнопка → тап по цели |
| Пауза / скорость | Space / F | Кнопки в HUD |
| Меню | Esc | Кнопка |

ПКМ намеренно не используется (отключена по требованиям рекламных платформ).

## 8. Архитектура кода

```
src/
  core/      игровой цикл, машина состояний, шина событий, время (пауза/скорость), сохранения, конфиг
  render/    рендерер, пост-эффекты, камера, пресеты качества, материалы, частицы
  world/     террейн, тропы, загрузчик уровней, генератор уровней
  entities/  враги, башни, снаряды, герой, солдаты (пулы объектов, инстансинг)
  systems/   волны, наведение, бой, экономика, статусы (огонь/лёд/стан), формации
  ui/        экраны и окна (Preact), HUD
  ads/       AdService + провайдеры (Stub, позже платформы)
  audio/     менеджер звука (шины, дакинг, mute при рекламе/сворачивании)
  data/      JSON-описания башен, врагов, уровней, магазина, локализаций
tools/       генераторы текстур/звуков/музыки, симулятор баланса, редактор уровней
```
Весь баланс (урон, цены, HP, волны) — в данных, а не в коде.

Производительность: инстансинг для толп (сотни солдат в кадре, как на референсах), пулы объектов, ограничение DPR на мобилках, ленивая загрузка биомов. Бюджет первой загрузки — до ~15–20 МБ (требования порталов).

## 11. Статус реализации (обновлено)

Решения по вопросам: платформа — по правилам Яндекс Игр без их SDK; ориентация адаптивная; CC0-ассеты; название «Хранители Долины»; RU + EN.

**Сделано**
- Три.js-движок: PBR-свет, тени, tilt-shift, bloom, SSAO (High), ACES, виньетка; пресеты Low/Medium/High/Auto с авто-понижением по FPS.
