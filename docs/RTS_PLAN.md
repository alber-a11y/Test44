# План разработки: RTS в мире «Хранителей Долины» (рабочее название «Хранители: Эпоха королевств»)

Стратегия в реальном времени в духе Age of Empires для браузера (ПК + мобильные), на движке, моделях, природе и стиле нашего tower defense.

**Статус:** черновик на согласование.

---

## 1. Идея в двух словах

Игрок начинает с ратушей и несколькими крестьянами в долине. Он собирает еду, дерево, золото и камень, строит дома и производственные здания, переходит из эпохи в эпоху, нанимает армию и уничтожает соперника.

Два режима:
- **Кампания** — 15 сюжетных уровней со своими целями: от «построй первые дома» до войны с несколькими соперниками (раздел 3.10).
- **Битва** (схватка) — свободный матч против 1–3 компьютерных соперников на сгенерированной карте.

Отличия от AoE, чтобы игра подходила для веба и коротких сессий:
- **Матч 12–25 минут**, а не час: быстрее сбор ресурсов, меньше эпох, ниже лимит населения.
- **Удобство на телефоне**: крупные кнопки, выделение «всех бойцов», кнопка «свободный крестьянин», автосбор после постройки.
- **Красивые сражения**: те же эффекты, частицы, звуки и VAT-толпы, что в TD, — на экране сотни юнитов.

## 2. Что берём из готовой игры (≈40–50 % основы)

| Готово в TD | Как используется в RTS |
|---|---|
| Three.js-движок, пост-обработка, пресеты качества, авто-качество по FPS | Без изменений |
| Шейдерный террейн, трава с ветром, деревья, скалы, хребты, 5 биомов | Основа карт; добавим маску «вырубленного леса» и «вытоптанной земли» |
| VAT-толпы (InstancedMesh + запечённые анимации) | Сотни юнитов за единицы draw call'ов — ключ к производительности RTS |
| Персонажи KayKit (рыцарь, варвар, маг, разбойник, скелеты), перекраска в цвета | Все боевые юниты; перекраска на 4 цвета игроков |
| Процедурные слон, носорог, мамонт, конь + посадка всадника | Кавалерия, боевые слоны, уникальные юниты |
| Частицы, снаряды, взрывы, всплывающий урон, тряска | Без изменений |
| Аудио-движок, синтез SFX/музыки, боевая музыка по событию | Новые звуки (рубка, кирка, стройка, «юнит готов», сигнал атаки) |
| Платформенный слой (как у Яндекса), реклама, пауза при скрытии вкладки | Без изменений |
| UI-кит на Preact, экраны, i18n RU/EN, сохранения, достижения | Меню, магазин, настройки — переиспользуем; HUD пишем новый |
| Headless-бот баланса, smoke-тест в CI, Playwright-скриншоты | Бот превращается в «ИИ против ИИ» для баланса |

**Модели, которые уже есть в паке KayKit Medieval Hexagon, но не используются:** ратуша/замок, дома (2 вида), казарма, стрельбище, кузница, рынок, церковь, таверна, лесопилка, шахта, мельница, водяная мельница, поле с пшеницей, колодец, башни (3 вида + башня с катапультой), стены (прямые, углы, ворота), частоколы, мосты. Всё это **в 4 цветах** (синий, красный, зелёный, жёлтый), плюс **стадии стройки** (леса, этапы A/B/C) и **руины**. Ещё есть ресурсы (брёвна, камень), ящики, телеги, флаги. Это почти полный набор зданий AoE.

## 3. Что новое (≈50–60 % работы)

### 3.1. Ядро симуляции (чистый TypeScript, как World в TD)
- **Детерминированный фиксированный тик** (20 Гц) и сид-генератор. Дают реплеи, сохранение посреди матча и задел под будущий мультиплеер.
- **Карта-сетка** 1×1 м поверх террейна: проходимость, лес, вода, здания. Карта 160×160 – 256×256 клеток.
- **Поиск пути:** иерархический A* на крупных регионах + flow field для групп + локальное расталкивание (упрощённый RVO) по пространственному хешу. Без «пробок» в воротах и толкучки у ратуши.
- **Приказы:** движение, атака, атака-движение, патруль, удержание позиции, сбор, постройка, ремонт, гарнизон, точка сбора здания.
- **Строй:** линия, коробка, рассыпной; дальнобойные за ближним боем.
- **Боёвка:** контр-система (копья > конница > лучники > копья), броня ближняя/дальняя, бонусный урон, осада по зданиям. Механики TD (черепаха щитоносцев, пробивающие болты, огонь, заморозка) переносим как способности.
- **Туман войны:** неисследовано / исследовано / видно. Сетка видимости обновляется 5 раз в секунду и подаётся текстурой в шейдер террейна.

### 3.2. Экономика и строительство
- **4 ресурса** как в AoE: еда (ягоды, охота, фермы, мельница), дерево (лес вырубается и исчезает), золото и камень (рудники).
- **Крестьяне:** несут ресурс к ближайшему складу, возвращаются, автоматически ищут следующий источник. Мужские и женские модели с инструментом.
- **Здания:** стройка с лесами и этапами, ремонт, гарнизон, очередь производства (до 5), точка сбора, уничтожение → руины.
- **Население:** дом +5, ратуша +5; лимит 100 на ПК, 60–75 на телефоне (настраивается пресетом качества).
- **Стены и ворота:** протяжка стены от точки до точки с автоуглами (модули из пака).

### 3.3. Эпохи и технологии
- **4 эпохи:** Поселение → Феодальная → Замковая → Королевская. Переход стоит ресурсов и требует 2 здания текущей эпохи. Смена эпохи меняет облик зданий (масштаб/детали) и открывает новые юниты.
- **~30 технологий:** кузница (атака/броня), лесопилка/шахта/мельница (скорость сбора), рынок (обмен ресурсов), церковь (лечение, обращение), университет-аналог (баллистика, архитектура).
- **Ветки улучшения башен из TD** становятся технологиями оборонительных зданий.

### 3.4. Юниты (стартовый ростер ~20)
| Здание | Юниты |
|---|---|
| Ратуша | Крестьянин |
| Казарма | Ополченец → Мечник → Рыцарь, Копейщик → Пикинёр |
| Стрельбище | Лучник → Арбалетчик, Застрельщик |
| Конюшня | Разведчик → Лёгкая конница → Тяжёлый рыцарь (конь + всадник) |
| Мастерская | Таран, Катапульта, Баллиста (процедурные модели) |
| Церковь | Монах/целитель (маг) |
| Замок | Уникальный юнит фракции (боевой слон / носорог / мамонт) + герой |

### 3.5. Фракции
- **v1 — 2 фракции:**
  - **Королевство** (синие): сильные лучники и стены.
  - **Красная Орда** (красные + скелеты-наёмники): дешёвая пехота, боевые звери.
- **Позже — ещё 2 цвета-цивилизации** (зелёные «лесные», жёлтые «торговцы») с бонусами и уникальными юнитами. Модели уже есть в паке.

### 3.6. ИИ-соперник
- **Слоистый ИИ:**
  - экономист: распределение крестьян, дома заранее, склады у ресурсов;
  - строитель: порядок застройки по шаблонам (build orders);
  - военачальник: сбор армии, разведка, атаки волнами, оборона базы, отступление.
- **3–4 уровня сложности:** через скорость реакции, качество решений и бонус сбора на «Тяжёлом» (честно помечен).
- **Тренировка баланса:** ИИ против ИИ в headless-режиме (как наш balance-бот), сотни матчей за минуты.

### 3.7. Управление
- **ПК:**
  - ЛКМ — выделение и рамка, ПКМ — приказ (контекстное меню браузера уже заблокировано);
  - группы Ctrl+1…9, двойной клик — все такого типа на экране;
  - горячие клавиши зданий и приказов, A — атака-движение;
  - камера: края экрана, WASD, колесо; клик по миникарте.
- **Телефон:**
  - тап — выбрать, тап по цели — приказ;
  - палец по пустому месту — двигать камеру, долгое нажатие + протяжка — рамка, щипок — зум;
  - кнопки «вся армия», «свободный крестьянин», «к ратуше»;
  - большая карточка команд внизу.
- **Миникарта** с туманом, пингами атак и кликом-переходом.

### 3.8. Режимы и контент
- **Кампания** — 15 уровней с сюжетом и своими целями, подробно в разделе 3.10.
- **Битва** (схватка): 1×1, 2×2, все против всех до 4 игроков, выбор фракции, сложности ИИ, размера карты и стартовой эпохи. Генератор карт: 5 биомов × 4 типа (материк, река с бродами, перевал, холмы).
- **Условия победы в Битве:** завоевание, чудо (удержать N минут), реликвии.
- **Оборона** (волны как в TD на движке RTS) — идея на после релиза, по контенту почти бесплатная.

### 3.10. Кампания: 15 уровней «Хроники Долины»

**Сюжет.** Поселенцы приходят в опустевшую Долину и закладывают новый очаг. Они растут от деревни до королевства, а затем дают бой Красной Орде и её хозяину — Пепельному Королю, финальному боссу из TD. Кампания идёт через все 5 биомов TD, и каждый акт открывает новую эпоху.

**Как устроен уровень:**
- **Брифинг:** карта-превью, рассказ героя, главная цель и 2 бонусные.
- **Звёзды:** ★ — выполнена главная цель, ★★ и ★★★ — бонусные (время, без потерь, особое условие). Звёзды дают монеты и открывают награды, как в TD.
- **Цели меняются по ходу уровня:** выполнил одну — появляется следующая, с репликой и пролётом камеры.
- **Постепенное открытие:** в каждом уровне доступны только изученные здания, юниты и эпохи, так что игрок не тонет в кнопках.
- **Сложность:** Лёгкая / Нормальная / Тяжёлая на выбор перед уровнем.
- **Награда за уровень открывает контент в Битве:** юниты, фракции, карты, героев.

**Что нужно для кампании, кроме самой игры:**
- **Система сценариев:** события (население ≥ N, построено X, юнит в зоне, время, разрушено здание) → действия (новая цель, реплика, пролёт камеры, появление войск, открытие карты, подкрепления союзнику, победа/поражение). Миссии описываются данными, а не кодом.
- **Трекер целей** в HUD и **брифинг** с превью карты.
- **Новые механики, которых нет в Битве:** захват поселений (флаг + перекраска зданий), сопровождение обоза, нейтральные и восставшие сёла, союзник с сигналами, смена дня и ночи, просьбы соседей.
- **Ручные карты:** генератор карт + ручная расстановка ключевых объектов. Для этого — простой **редактор карт в браузере** (dev-режим): кисти леса, воды и холмов, расстановка зданий и юнитов, триггерные зоны, экспорт в JSON.
- **Реплики с портретами:** рендер героев, как иконки в TD, озвучка не нужна — текст и звуки-«бормотание».
- **Экран карты кампании:** как карта уровней TD, по актам и биомам, со звёздами.
- **Автосохранение на контрольных точках:** после каждой выполненной цели, чтобы на портале можно было закрыть игру и продолжить.

### 3.9. Мета-прогресс, магазин, реклама (по модели TD, «выше среднего»)
- **За звёзды кампании и победы:** монеты → постоянные бонусы (стартовые ресурсы, скорость сбора +5 %, скины зданий/знамён, герои).
- **Interstitial:** между миссиями и после матча; не чаще раза в 60 с, первый — после 3-й миссии.
- **Rewarded (с лимитами, чтобы не ломать баланс):**
  - x2 награда за победу;
  - «Обоз с ресурсами» раз в эпоху;
  - мгновенная технология раз за матч;
  - воскрешение героя;
  - уникальные предметы 3/3 (как в TD).
- Пауза игры и звука на время рекламы, работа со скрытием вкладки — уже готовы.
- **Ежедневная награда, колесо, достижения** — переносим.

## 4. Технические риски и как их снимаем

| Риск | Решение |
|---|---|
| Поиск пути для 200+ юнитов тормозит на телефоне | Иерархический A* + flow fields с кэшем, симуляция 20 Гц отдельно от рендера, при необходимости — в Web Worker |
| Отрисовка 200+ юнитов + 150 зданий | VAT-инстансинг уже держит сотни юнитов; здания — инстансы по типу/цвету; LOD теней |
| Сложное управление на телефоне | Отдельная схема ввода и крупный HUD; ранний прототип управления на телефоне в этапе 1 |
| ИИ «тупит» или читерит | Слоистый ИИ + тысячи матчей ИИ против ИИ для настройки |
| Короткие сессии на порталах | Автосохранение матча (симуляция сериализуется) и короткие миссии |
| Разрастание объёма | Вертикальный срез первым; каждая следующая фича — только после играбельного предыдущего этапа |

## 5. Архитектура кода

Предлагаю **тот же репозиторий, отдельное приложение**:
```
src/
  shared/   ← переезжает из TD: render (Engine, Terrain, Grass, Decor, VAT, Particles), audio, platform, ads, ui-kit, save, i18n
  td/       ← текущая игра (без изменений поведения)
  rts/
    sim/      ← World, Map/Grid, Pathfinding, Units, Buildings, Economy, Tech, Fog, Commands
    ai/       ← Economy/Builder/Military-менеджеры, build orders
    game/     ← Session, Input (mouse/touch), Selection, Camera
    render/   ← RtsView, BuildingVisual, FogLayer, Minimap, SelectionRings, PlacementGhost
    ui/       ← HUD, CommandCard, ResourceBar, Minimap UI, экраны
    data/     ← units, buildings, techs, ages, civs, missions
index.html (TD) + rts.html (RTS) — две точки входа Vite, два отдельных билда/ZIP для порталов
```
Плюсы: исправления в движке сразу достаются обеим играм, TD продолжает собираться и тестироваться в CI.

**Кампания растёт вместе с движком.** Каждый этап заканчивается новыми играбельными уровнями, поэтому проверять игру можно с самого начала: после этапа 1 — уровень 1, после этапа 2 — уровни 1–3 и так далее. Уровни кампании одновременно служат приёмочными тестами механик.

**Объём:** примерно в 3 раза больше, чем TD (кампания со сценариями добавила к первой оценке). Самые тяжёлые этапы: 1 (фундамент ввода и пути), 3 (бой), 5 (ИИ) и 8 (финальные уровни кампании). После этапа 4 будет 9 уровней кампании, после 7 — полноценная Битва, после 8 — законченная игра.
